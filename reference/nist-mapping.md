# NIST AI RMF Mapping

This table shows which parts of NIST AI RMF 1.0 each template relates to. Using these templates doesn't make a company compliant or certified.

Before publishing, check each row against NIST AI 100-1 and the NIST AI RMF Playbook, then tick "Verified".

| Template | Function | Category | Verified |
|---|---|---|---|
| AI use policy | Govern | GOVERN 1: Policies, processes and procedures | [ ] |
| AI use case check | Map / Measure / Govern | MAP 1: Context; MAP 5: Impacts; GOVERN 6: Third parties | [ ] |
| AI register | Govern / Manage | GOVERN 1; MANAGE 1: Prioritize and respond | [ ] |
| AI incident steps | Manage | MANAGE 4: Response, recovery and communication | [ ] |
| Test plan | Measure | MEASURE 2: Evaluation for trustworthy characteristics | [ ] |
| Generative AI risk checks | Map / Measure | NIST AI 600-1 (Generative AI Profile) | [ ] |
| Metrics | Measure | MEASURE 3: Tracking risks over time | [ ] |
| Roles | Govern | GOVERN 2: Accountability | [ ] |

**Not covered in this version:** GOVERN 3 (workforce diversity), GOVERN 4 (organizational culture, partly covered), GOVERN 5 (external stakeholders).
