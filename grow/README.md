# Optional Templates

You don't need these to get started. Add one when you run into the problem it solves.

| Template | Worth adding when | Works with |
|---|---|---|
| [Test plan](test-plan.md) | AI output reaches customers or affects decisions | The "tested on real examples" box in the use case check |
| [Generative AI risk checks](genai-risks.md) | You're building features with chatbots or text or image generators | Section 1 of the use case check |
| [Metrics](metrics.md) | You need to show whether AI is working and safe over time | Register reviews |
| [Roles](roles.md) | Several teams use AI and it's unclear who approves what | Section 3 of the use case check |

You can add your own templates to this folder. Link them from this table so people can find them.
