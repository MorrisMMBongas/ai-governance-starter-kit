# Generative AI Risk Checks

NIST AI 600-1 (Generative AI Profile, July 2024) lists 12 risks that apply to generative AI. I wrote one question for each. For any row where you answer yes, write down how you'll handle it.

| NIST risk | Could this happen here? | Yes / No |
|---|---|---|
| CBRN information or capabilities | Could it give dangerous chemical, biological, radiological or nuclear information? | |
| Confabulation | Could it state false facts or invent sources people trust? | |
| Dangerous, violent or hateful content | Could it produce harmful content? | |
| Data privacy | Could personal data be entered, stored or revealed? | |
| Environmental impacts | Is usage large enough that energy use matters? | |
| Harmful bias or homogenization | Could it treat groups of people unfairly? | |
| Human-AI configuration | Could people trust it too much or not know it's AI? | |
| Information integrity | Could it be used to mislead people? | |
| Information security | Could someone trick it, or use it to attack? | |
| Intellectual property | Could output copy protected content? | |
| Obscene, degrading and/or abusive content | Could it produce abusive or explicit content? | |
| Value chain and component integration | Do we rely on third-party models or data we can't check? | |

> Before publishing, check the names against NIST AI 600-1.
